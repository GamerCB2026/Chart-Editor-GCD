# Chart Editor GCD
Este Chart Editor busca ofrecer una experiencia similar a la de V-Slice. Aunque desarrollar este formato puede ser complicado, estamos trabajando para que muchas personas puedan usarlo, crear charts y colocar eventos. Esperamos que este proyecto sea de su agrado. Se agregarán más funciones con el tiempo.

# ¿Qué se agregó?
- **Tema claro funcional:** puedes cambiar entre el tema claro y el oscuro. El tema claro puede ser intenso para la vista si no estás acostumbrado, mientras que el tema oscuro puede resultar más cómodo.
- **Modo vertical y mejoras para móvil:** ahora puedes trabajar con el editor en orientación vertical o ajustar el tamaño de la grilla para que sea más cómoda en pantallas pequeñas. También se añadieron controles de pantalla completa y ajustes para la orientación.
- **Importación de charts desde el inicio:** al crear un proyecto puedes importar directamente un archivo `.fnfc`, sin tener que crear primero un chart vacío. El Import Center también permite abrir archivos de Codename Engine, Psych Engine (formatos moderno y legacy) y Legacy (FNF vanilla/Kade).
- **Archivador de proyectos y audio:** guarda tus charts y sus audios en el navegador para volver a abrirlos después. Si un proyecto importado no tiene audio, puedes volver a vincular sus pistas.
- **Más herramientas de edición:** selecciona todas las flechas o solo las del jugador o del oponente, usa selección múltiple, copia, corta y pega notas, y deshaz o rehace cambios. También puedes mover notas y eventos juntos entre casillas.
- **Modo Libre:** coloca flechas en posiciones precisas dentro de una casilla y ajusta el imán para elegir cuánto se acercan a la cuadrícula. Las posiciones libres se conservan al guardar el chart.
- **Mejoras para notas y eventos:** se pueden conservar varias flechas en el mismo punto y apilar varios eventos en una casilla. La edición de eventos incluye Focus Camera, Scroll Speed, Set Camera Bop, Set Health Icon, Zoom Camera y Play Animation.
- **Importación de eventos personalizados:** importa eventos de V-Slice desde archivos `.hxc`. Los eventos que el editor todavía no reconoce se conservan al importar el chart y pueden editarse después de importar su definición.
- **Eventos de notas personalizadas:** importa notas personalizadas o elige las disponibles para agregarlas al chart. La página también indica qué archivos necesita el mod para que esas notas funcionen dentro del juego.
- **Dificultades, variaciones y metadata:** administra las dificultades y variaciones de una canción, completa dificultades faltantes y edita la metadata de cada variación, incluidos el BPM, el compositor, el charter y los personajes. También puedes descargar el chart y la metadata de la variación activa.
- **Visualizador de personajes:** carga personajes para Player y Opponent, prueba sus animaciones, voltéalos y guarda personajes con sus recursos en el navegador para reutilizarlos.
- **Audio y reproducción mejorados:** consulta las formas de onda, controla el volumen y el silencio del instrumental y las voces, y activa los hitsounds. También se corrigieron errores de audio y visualización, incluido el evento Focus Camera.
- **Ajustes de apariencia y paneles:** elige entre los temas claro y oscuro, ajusta el zoom de la grilla y muestra u oculta los paneles de audio y de controles.
- **Stage Editor anunciado:** se agregó su sección de proyectos como vista previa; la edición de escenarios todavía está en construcción y llegará próximamente.
- **Optimización:** se optimizó aún más Chart Editor GCD.

# ¿Cuál es el objetivo de este Chart Editor?
El objetivo es crear herramientas para personas con pocos recursos o que usan dispositivos móviles, para que puedan iniciarse en el modding con facilidad. La idea no es competir con otros proyectos que tienen el mismo objetivo, sino ayudar a que más personas puedan usar herramientas de modding de FNF en celulares y otros dispositivos, desde un simple enlace web. Espero que esta herramienta les sea de mucha ayuda.

# ¿Qué incluirá la V0.8.3 B1 «Editor GCD Update»?
La idea principal era sencilla: mejorar el aspecto visual del Chart Editor y añadir mejoras. En cuanto a lo visual, me refiero al Stage Editor GCD y al Animation Editor GCD. Sin embargo, gracias al apoyo que le han dado a este proyecto, los planes cambiaron. Ahora me dedicaré a crear un Stage Editor GCD funcional y un Animation Editor GCD como vista previa, junto con el futuro Camera Editor GCD. De este modo, podrán tenerlo todo en una sola página. Al principio era un proyecto pasajero, pero ahora se está convirtiendo en un proyecto al que le tengo mucho aprecio.
