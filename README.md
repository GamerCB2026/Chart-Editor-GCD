# Chart Editor GCD
Este Chart Editor Prácticamente intenta ser como el de V Slice ósea que puede que sea algo complicado de hacer pero que se esta intentando este formato hará que muchos puedan usarlo y chartear colocar eventos y mucho mas espero este proyecto sea de su agrado se agregaran mas cosas acorde el tiempo pase

# Que Se Agrego?
- Se agrego el formato Vertical y no solo eso también se solucionaron varios bugs de audio o visuales o de el evento único FocusCamera

- Tambien se agregaron cosas nuevas como el anuncio de el proximo Stage Editor o tambien cosas como el importar Chart al inicio para no crear un proyecto y importar chart si no simplemente importarlo desde el inicio

# Modo De Miembros
Este formato hace que solo los miembros de el canal tengan acceso a este apartado simplemente por medio de un código no publico que solo ellos podrán ver de esa forma tendrán su exclusividad desde antes por apoyar el canal de @GamerCB2026

# Cual Es El Objetivo de este Chart Editor?
El objetivo es poder hacer que todos los creadores de FNF puedan chartear para V-Slice sin problemas con eventos de todo tipo eso si esta pasando por su fase Beta

Seguramente sea la ultima versión de la Beta 1 pero en esta versión la llamare "Event Update" ya que contendrá todos los eventos de el FNF V-Slice Original también agregare el sistema de Editar para regresar, devolver, seleccionar todas las flechas, deseleccionar todas las flechas etc. Entonces será la ultima Update de la Beta 1 y Posiblemente tengan el visual de el Stage Editor no funcional así como la primer versión de el Chart Editor GCD pero bueno hay será dependiendo de el progreso pero en mi caso ya tengo los objetivos claros
